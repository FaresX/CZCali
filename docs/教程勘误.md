# 教程核对与勘误（2026-10-12）

核对依据：仓库原论文全文，重点为 Fig. 2、Fig. 13–15 与附录 B/H/I/J/K；同时核验 APS 论文页面。当前仓库没有控制代码或本机实验数据，因而此处核对的是教学内容，不是设备参数验证。

| 原问题 | 修正 | 依据/影响 |
|---|---|---|
| QPT 公式缺少整体分母 | F=(Tr(Rᵀideal R)+d)/(d(d+1)) | 原文 J1；理想门应返回 1 |
| CZ 的 Pauli 映射及网页矩阵错误 | XX↔YY 为正；XY↔−YX；IX↔ZX、IY↔ZY；固定项为 II/IZ/ZI/ZZ | 直接计算 CZ P CZ†；修正网页矩阵生成代码 |
| 用迹保持说明无显著泄漏 | 迹保持是最大似然重建的约束，泄漏需独立测量 | 原文附录 J |
