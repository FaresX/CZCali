# CZ 门校准 · 资料索引

第一次做校准，先读 **[CZ 校准入门手册](CZ校准入门手册.md)**。它按准备、测量、验收和排错组织，提供条件 Ramsey 入门路径，之后再学习论文的 JAZZ 与 PPO 优化。

| 文件 | 用途 |
|---|---|

| [论文方案笔记](DTC_CZ校准方案总结.md) | 原文物理模型、参数表、公式与附录导航 |
| [网页版实验手册](cz-calibration.html) | 按真实测量流程组织操作卡、条件 Ramsey 序列与验收；论文图解在折叠参考区 |
| [教程勘误](教程勘误.md) | 已发现的问题、修正及依据 |

原文：Li 等，[Realization of High-Fidelity CZ Gate Based on a Double-Transmon Coupler](https://doi.org/10.1103/PhysRevX.14.041050)，Phys. Rev. X 14, 041050 (2024)。[本地 PDF](../resources/PhysRevX.14.041050.pdf) 含附录 A–L。

论文案例实现 48 ns、99.90 ± 0.01% CZ。这些数值是参考结果，需在自己的设备重新标定。仓库目前没有可直接运行的校准代码。

推荐流程：读出/XY 粗标 → idle → XY 精标 → Z 失真补偿 → 条件相位/波形 → VZ → 独立验证与 RB/LRB → 门长及稳定性。论文复现重点回查附录 H（失真）、I（优化）、K（精度）、L（误差预算）。
