# CZ 校准入门手册

本手册面向第一次操作超导量子比特 CZ 校准的实验人员，以双 transmon 耦合器（DTC）为案例。目标是先得到可验证的 CZ，再提高保真度。它不提供仪器驱动；当前仓库只有论文与教学资料，没有可直接运行的校准程序。

来源：[Li 等，Phys. Rev. X 14, 041050 (2024)](https://doi.org/10.1103/PhysRevX.14.041050)，本地论文位于 `../resources/PhysRevX.14.041050.pdf`。下文“建议”是教学与工程建议；论文数值集中在末尾。详细公式见 [论文笔记](DTC_CZ校准方案总结.md)，修正理由见 [勘误](教程勘误.md)。

## 1. 先理解要校准什么

CZ 在基底 `|00⟩, |01⟩, |10⟩, |11⟩` 中为 `diag(1,1,1,-1)`：只给 |11⟩ 多一个 π 相位。磁通脉冲使耦合变强，但通常也给两个比特各自带来额外相位，因此要校准三项：

1. 空闲点（idle）：让不用 CZ 时的残余 ZZ 足够小。
2. 耦合器磁通脉冲：让条件相位为 π，并减少泄漏与脉冲尾巴。
3. 两个 virtual-Z（VZ）：通过更新后续 XY 驱动的帧相位，补偿单比特附加相位。

“Z 脉冲”在此指耦合器的磁通控制波形；VZ 是软件帧更新，两者不能混用。

若一次脉冲近似为对角门，四个态的相位为 φ₀₀、φ₀₁、φ₁₀、φ₁₁，则

$$\theta_{CZ}=\phi_{11}-\phi_{10}-\phi_{01}+\phi_{00}=\pi\pmod{2\pi}.$$

规定能量 E 用焦耳、ZZ 用角频率时：

$$\zeta=(E_{11}-E_{10}-E_{01}+E_{00})/\hbar,\quad \theta_{CZ}=-\int\zeta(t)dt.$$

若能谱以 E/ℏ 表示，定义中不再除 ℏ。若 ZZ 用 Hz，则相位是 `−2π∫f_ZZ dt`。负号来自 `U=exp(−iHt/ℏ)`；实验拟合符号还取决于末端 π/2 轴的约定。±π 表示同一个 CZ 条件。

**先做符号检查**：用已知正方向的帧相位更新测一次 Ramsey，确认软件正号、测得相位正号与比特顺序，再开始自动拟合。

## 2. 开始前的准备与记录

需要两比特 XY 控制、耦合器快速磁通控制、稳定 dc 偏置、同步时钟与读出。仪器型号不必与论文一致。dc 线圈链路与快速磁通链路分开：不能把论文 dc 线路的 <1.6 kHz 低通搬到用于 ns 脉冲的快速线路。

先建立以下实验能力：

- 能做频谱、Rabi、Ramsey、T₁ 和 echo，能制备并区分两个比特的 |0⟩、|1⟩。
- 能读出单发 IQ，并用制备态验证分类结果；聚类后必须把簇对应到物理态。
- 能保存实际上传波形、采样率、滤波配置、触发延迟及软件帧设置。
- 测泄漏时还要能区分数据比特 |2⟩；DTC 的完整泄漏表征还需识别耦合器激发，或采用经过验证的替代测量。

每次扫描保存：日期、芯片/比特对、dc 电流、磁通换算、XY 校准版本、脉冲版本、重复次数、shots、原始 IQ/计数、拟合值与不确定度。幅度必须记录单位（V 或明确的归一化值），不要只记“0.3”。

先按团队已确认的器件工作范围设置扫描边界。复位/等待时间应通过残余激发和脉冲尾巴验证；不能用任意固定等待时间掩盖失真。

## 3. 推荐顺序

读出与 XY 粗标 → idle 定标 → idle 处 XY 精标 → 磁通失真补偿 → 固定门长粗标 CZ → 精标条件相位/波形 → 固定波形校 VZ → 独立验证 → 门长与稳定性优化。

每一步先保存可回退的参数。改变 idle、滤波器或门长后，应重新检查相关的下游校准；改变 Z 波形后，必须重校 VZ。

## 4. 第一步：读出与 XY 粗标

**操作**：扫读出频率和幅度，测 |0⟩/|1⟩ 的 IQ 分布；用频谱、Rabi、Ramsey 粗标两个比特的频率、π/π/2 幅度，再调 DRAG 参数。

**记录**：分类矩阵 `M[i,j]=P(判为 i | 制备 j)`，包含制备误差的限制；确认读出功率不会明显激发或扰动系统。

**通过条件**：能够重复制备两种态，Ramsey 有足够可见度且拟合稳定。此时只要求具备测 idle 的能力，最终单比特精标在 idle 确定后进行。

## 5. 第二步：找到 idle 点

新手建议先用两组条件 Ramsey 建立直觉：

1. 选 Q1 为探针，Q2 制备 |0⟩。Q1 做 π/2 → 等待 τ → 末端分析 π/2 → 读出。
2. Q2 改为 |1⟩，重复相同 τ 扫描。两组使用相同驱动频率和分析约定。
3. 拟合两条带衰减振荡，提取频率差 `f_ZZ=f_probe(Q2=1)−f_probe(Q2=0)`。末端相位扫描/双正交分析有助于确定符号。
4. 扫 dc 偏置，找 |f_ZZ| 小且相干性良好的区域；在候选点重复测量，报告误差条。

如果频率差小于分辨率，不要宣称“精确为零”。增加可用 Ramsey 时间或使用原文 **Fig. 2(a) 的完整 JAZZ 回波序列**；普通 Ramsey 的单条频率不能直接当 ZZ。原文 JAZZ 的 `ζ=2(ω_m−ω_b)` 使用其特定 t 定义，不能直接套到任意等待序列。

**通过条件（建议）**：按允许的空闲条件相位预算判断，例如 `2π|f_ZZ| τ_idle` 是否足够小，同时检查同时操作时的单门表现。论文的 −6.3 kHz 不是所有芯片的验收标准。

确定 idle 后重新精标 XY 频率、幅度、DRAG 和帧相位；用单独及同时 RB 检查单比特质量。

## 6. 第三步：测磁通脉冲失真并补偿

线路会把理想波形变成带过冲和尾巴的实际磁通。先纠正线路，再优化门。

**短期测量**：选择数据比特频率对磁通敏感、又能保持可用相干性的传感点。建立叠加态，施加小幅短方波，扫描脉冲结束后的等待 t，用 X/Y 两个分析轴恢复相位。配套测无脉冲参考，扣除失谐相位；对相位解缠后拟合。脉冲应留在已确认的能谱范围内。

**长期测量**：比特在基态时先施加长方波，扫描关断后的等待 t，再做固定时长 Ramsey。这种方法不需要让叠加态持续整个长等待。

论文附录 H 用多指数模型拟合相位；要按各序列的积分窗口使用模型，不能把电压步响应与积累相位当成同一个量。拟合出的时间常数和幅度需要通过具体 AWG 的滤波定义转换为预畸变参数，并验证稳定性、幅度是否越界及上传后的真实波形。

**通过条件（建议）**：相同序列下，补偿后的尾部相位残差下降；换幅度、脉冲长度和重复间隔仍能改善。如果多指数参数不稳定，先缩减模型并检查触发/参考相位，而不是持续增加拟合项。

**完成后返回 idle 并复核 XY**。论文的传感磁通 0.42 与时间常数不能复制为本机配置。

## 7. 第四步：获得第一个 CZ

### 7.1 固定门长，粗扫幅度

先选平滑、首尾回到 idle 的脉冲，在设备允许范围内固定门长并粗扫幅度。Slepian 是论文初值；初学者也可先用平滑余弦形状建立测量流程。暂时只调整少量参数。

每个候选波形做条件 Ramsey：Q1 在叠加态，分别让 Q2 为 |0⟩ 和 |1⟩，在 Ramsey 中插入待校准脉冲；扫描末端 π/2 相位，比较两组相位得到 θ_CZ（符号须按第 1 节确认）。对 Q2 做交换角色的交叉检查。

**观察**：找 θ_CZ 穿过 π 的连续分支，同时检查可见度、|2⟩ 和耦合器激发。读出 |11⟩ 的概率高不能证明实现 CZ，因为 CZ 只改变相位。

### 7.2 放大误差并精调

幅度初值附近再采用原文 Fig. 13(a) 的 JAZZ-N，逐步增大重复次数；理想条件下论文给出

$$P_1=[1-\cos((2k+1)\theta_{CZ})]/2,\quad N=4k+1.$$

高 N 会出现多个峰，先低 N 定分支，再高 N 精扫，并在低 N 和独立条件 Ramsey 中复核。不要只挑一次扫描里最高的单点。

波形精调可使用少量参数扫描或优化器；论文采用 Fig. 13(b) 的 JAZZ2-N + PPO。**PPO 是进阶工具，不是新手必须先搭建的模块。** 使用它前必须明确完整回波序列、N 的定义、幅度/带宽/端点约束以及 reward 的测量噪声。N 不是脱离序列定义的任意“CZ 重复次数”。

序列存活概率是优化目标，不等于单次门平均保真度；高 reward 还需独立泄漏与 RB 验证。三次样条可能在控制点之间过冲，上传前检查整条采样波形。

**通过条件（建议）**：独立条件 Ramsey 得 θ_CZ≈π，重复扫描结果一致，没有明显可见度塌陷，泄漏符合自己的误差预算。

## 8. 第五步：固定波形，补偿 VZ

分别测两个比特，另一比特放 |0⟩。用有/无 CZ 波形的 Ramsey 比较测附加相位；用相同总时间参考扣除驱动失谐，必要时使用回波参考。VZ 符号由本控制软件的帧约定决定，应用补偿后必须重测，不能直接照搬角度。

在本手册的对角相位约定下，需要去掉的单比特相位为 `φ₁₀−φ₀₀` 和 `φ₀₁−φ₀₀`。原论文用 θᵢ/2 表示每次脉冲诱导的相对相位；图中斜率不能不加转换地当成任意 SDK 的 RZ 角。

**通过条件**：补偿后，另一比特为 |0⟩ 时附加相位接近零；为 |1⟩ 时相对多出 π。用两个方向的条件 Ramsey 复核。可在二维 VZ 局部扫描或两比特 RB 目标上微调，期间固定 Z 波形。

## 9. 第六步：验证与报告

先在一组未用于优化的数据上复核条件相位、单比特补偿和泄漏。制备 |++⟩ 后应用 CZ，可通过状态层析/相关性检验纠缠；完整 QPT 是可选诊断，受 SPAM 影响。

正式评精度用 SRB 与交错 CZ 的 IRB，统一 Clifford 分解和时长约定，使用多条随机序列及多个长度。报告拟合模型、误差条、随机序列数和 shots，检查拟合残差。IRB 的门误差提取依赖噪声假设，不能从单条存活曲线保证任意输入态保真度。

存在泄漏时，使用可观测计算子空间总占据的 LRB。DTC 的计算子空间同时要求两个数据比特在 |0/1⟩ 且耦合器在基态；只测数据比特 |2⟩ 会漏掉耦合器激发。若没有完整观测能力，明确报告“数据比特泄漏”及其局限。

论文的 LRB 定义中，d=4，平均保真度为

$$\bar F=1-L_1^{CZ}/4-r_{CZ}.$$

它的 r_CZ 已包含部分泄漏贡献，不能再机械地减去全部 L₁。代入论文的 `r_CZ=0.090%`、`L₁=0.027%`，得到 `99.90325%`，与报告的 99.90% 一致。

QPT 在采用相同 Pauli 归一化与迹保持模型时用

$$F=[\operatorname{Tr}(R_{ideal}^{T}R)+d]/[d(d+1)].$$

理想 CZ 对照自身应得 F=1。迹保持若被重建器强制施加，就不能再当无泄漏的证据。

最后尝试相邻门长：每个门长都重新校波形和 VZ，再比较精度。稳定性测试期间记录重标了哪些参数；论文 12 h 测试中 CZ 只优化一次，但每次 RB 前重标了单比特门。

## 10. 常见问题

| 现象 | 优先排查 | 下一步 |
|---|---|---|
| idle 附近测不到振荡 | ZZ 很小、失谐参考不一致 | 两组条件 Ramsey 差分；按原图使用 JAZZ 基线相位 |
| 幅度扫出多个“最佳值” | 高 N 的多峰与相位绕转 | 回到低 N 和连续条件相位扫描定分支 |
| 相位对了但对比度下降 | 泄漏、退相干、制备/读出漂移 | 查高能级占据、相干性及参考数据 |
| 单次脉冲正常，连打变差 | 长尾、复位不足、重复相关失真 | 扫重复间隔与脉冲列，复核长期补偿 |
| 改波形后 RB 下降 | VZ 已失配 | 固定新波形重新校两个 VZ |
| VZ 越补越差 | 帧更新符号、角度单位、θ/2 混用 | 已知帧更新 Ramsey 验证，确认 rad/degree |
| PPO reward 高但 RB 差 | 目标过拟合、相位分支或泄漏 | 独立随机序列、条件 Ramsey 和泄漏测量 |
| QPT 只有约 96%，RB 更高 | SPAM 和不同评价方法 | 比较参考 QPT、分类矩阵与 RB 假设 |

## 11. 一次校准应交付什么

- [ ] idle 偏置、ZZ 估计与不确定度，以及该点的 XY/读出校准版本。
- [ ] 失真测量原始数据、补偿参数、补偿前后对比。
- [ ] 最终上传波形、单位、采样率、门长、零 padding 定义和滤波配置。
- [ ] 两个方向的条件 Ramsey、VZ 角度及软件符号约定。
- [ ] 独立验证数据、泄漏观测范围、SRB/IRB/LRB 拟合与误差条。
- [ ] 重复测量记录、重标历史，以及适用的实验误差预算。

## 12. 论文案例：用于对照，需重新标定

| 项目 | 论文值 | 本机使用方式 |
|---|---|---|
| idle 磁通 φ_ex/2π | 0.309 | 重新测电流/电压到磁通的换算及 idle |
| idle ZZ / 2π | −6.3 kHz | 按自己的空闲相位预算验收 |
| 最大 ZZ / 2π | −82.5 MHz | 能谱范围内实测，不用峰值推算整条门相位 |
| CZ 波形总长 | 48 ns，含首尾各 2 ns 零 padding | 扫门长时重新校波形/VZ |
| PPO 参数 | 20 控制点，2 GSa/s，约 100 epoch | 只是该实验配置，不是收敛保证 |
| 平均 CZ 保真度 | 99.90 ± 0.01% | 实测评估；读出保真度不是门保真度的普适上限 |

先得到可重复的相位与泄漏测量，再逐步提高精度。论文附录 H、I、K 分别是失真、脉冲优化和正式评精度的回查入口。
