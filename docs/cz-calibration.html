开始

实验台前：确认范围与约定

本页面向 DTC。操作建议与论文案例分开；当前仓库没有仪器驱动或本机数据。数值扫描范围、shots、复位时间和误差门槛需要按自己的设备确定，论文的 0.309 / 48 ns 不是默认配置。

链路与状态

  • 同步两比特 XY、读出和耦合器快速磁通触发，确认相对延迟。
  • dc 线圈偏置与快速磁通分开；<1.6 kHz 低通属于 dc 线路。
  • 先确认可用能谱范围及幅度边界，记录 V ↔ 磁通换算。系统带宽和 AWG 采样率是不同的量。
  • 每次 shot 都复位或等待，并用残余激发与尾部相位确认等待足够；读出发生在门完成后。

统一单位与相位

  • 基底顺序：|00⟩、|01⟩、|10⟩、|11⟩，第一位是 Q1。
  • ζ 用 rad/s 时 θCZ=−∫ζdt；ZZ 用 Hz 时加 2π。E 用能量时 ζ=(E₁₁−E₁₀−E₀₁+E₀₀)/ℏ。
  • 用已知帧更新测 Ramsey，验证驱动帧符号及 rad/degree，再做 VZ。
  • 扫描分析相位拟合 P=A+B cos(α+φ)；φ 的符号依赖分析脉冲约定，报告时保持一致。
0 粗标1 idle → XY 精标2 失真 → 回 idle3 CZ4 VZ5 独立验证

每一步保存可回退版本。改变 idle / 滤波链路后复核下游步骤；改变 Z 波形或门长后重校 VZ。先粗扫确定连续分支，再局部精扫；将参考点穿插在扫描中，用它识别漂移。

0 · 读出与 XY 粗标

进入前
确认触发、复位和读出链路可用。
固定项
当前粗偏置、脉冲时序；每次只调一类参数。
扫描项与执行顺序
读出频率/功率 → 制备 |0⟩/|1⟩ 的单发 IQ → 频谱 → Rabi → Ramsey → DRAG。
测量与参考
保存 IQ 与每个制备态的计数；聚类后把簇对应到物理态。泄漏测量需另加 |2⟩ 分类。
处理与产出

通过条件：能够重复制备 |0⟩/|1⟩，Ramsey 可见度足够且拟合稳定；此处只是粗标。

未通过先查：残余激发、读出诱导跃迁、分类簇标签、触发延迟。

1 · 扫 dc 找 idle，再精标单比特

进入前
两比特 π/π/2 已粗标，已知 dc 扫描范围。
固定项
每个偏置点两组采用相同探针驱动频率、分析轴、等待 τ 网格。
扫描项与执行顺序
外层扫 dc；每点 Q2=c=0/1 各做 Q1 Ramsey 的 τ 扫描。先粗后细；候选点重复测量。
测量与参考
测 Q1 振荡，用双正交分析或已知分析相位确定频率符号；必要时交换探针方向。Q2 的 T₁ 会影响 c=1 组，等待范围应兼顾信号与弛豫。
处理与产出
拟合衰减振荡，f_ZZ=f_probe(c=1)−f_probe(c=0)。得到 dc–ZZ 曲线、不确定度及候选点的相干性。小于分辨率只报范围；需要更高灵敏度时按论文 Fig. 2(a) 实现完整 JAZZ 回波。

通过条件：空闲条件相位 2π|f_ZZ|τ_idle 满足自己的预算。选定 idle 后重标 XY 频率/幅度/DRAG，并用单独及同时 RB 检查。

未通过先查：把单条 Ramsey 频率当 ZZ、符号不确定、c=1 组弛豫、dc 漂移。原文 ζ=2(ω_m−ω_b) 不能套到本图的 τ。

实验

2 · 分时段测失真，验证预畸变

进入前
找出磁通灵敏且相干性可用的传感点；确认小脉冲不跨入未表征区。
固定项
短期：方波幅度/长度固定；长期：长方波及 Ramsey 探测窗固定。
扫描项与执行顺序
短期按图扫关断后 t；长期先在基态打长方波 → 等待 t → π/2 → 固定探测窗 → X/Y 分析。两种实验分别覆盖可辨识的时间尺度。
测量与参考
测 X/Y 分量、解缠相位，扣除相同总时长的无脉冲参考。长等待在制备叠加态之前，避免让叠加态持续整个等待。
处理与产出
按对应积分窗口拟合多指数响应，保存参数及残差；用 AWG 的实际滤波定义转为补偿设置。检查上传波形过冲、饱和、端点与触发。

通过条件：相同序列下尾部残差下降；换幅度、长度和重复间隔仍有效。完成后返回 idle，复核频率与 XY。

未通过先查：相位解缠错误、参考失谐、触发偏移、参数不可辨识、滤波定义不匹配；不能直接复制论文 Table V。

3 · 固定门长，粗标再精调 CZ

进入前
idle 与 XY 精标完成，失真补偿已验证；能测高能级占据。
固定项
初始平滑波形形状、总门长、滤波配置和 idle；先不优化 VZ。
扫描项与执行顺序
外层粗扫 Z 幅度；每幅度依次测 c=0/1 两组分析相位 α。对连续 θ_CZ≈π 分支局部细扫，再增加重复序列灵敏度。
测量与参考
两条条件 Ramsey fringe 的相位差给 θ_CZ，约定符号后解缠。交换 Q1/Q2 复核，同时测可见度及 |2⟩ / 耦合器激发。无 Z 参考保持相同总时间。
处理与产出
保存幅度–相位/可见度/泄漏曲线。精调可少参数扫描；进阶按 Fig. 13(a/b) 使用完整 JAZZ-N / JAZZ2-N。低 N 定分支、高 N 精调，最后回低 N 复核。PPO 是可选工具，20 控制点并非通用配置。

通过条件：独立条件 Ramsey 的相位差接近 π，可见度未明显塌陷且泄漏符合预算。完整采样波形在边界内，三次样条无越界过冲。

未通过先查：高 N 多峰误选、相位绕转、非绝热泄漏、长尾与复位不足。单点高存活概率不等于单门保真度。

Z 波形、门长、idle、XY；只改变两个帧补偿角。

01

器件与耦合原理

DTC 由 4 个 transmon 组成：Q1 / Q2 为数据比特，C3 / C4 为耦合器。 JJ3、JJ4 与额外结点 JJ5 组成超导环，外磁通 φex 经该环调控两比特间的 ZZ 相互作用。

玩具模型：p 模式 + m 模式

DTC 可等效为一个定频 transmon P（p 模式，5.495 GHz）与一个 CSFQ M（m 模式，5.373 GHz）：p 模式提供"固定"耦合，m 模式频率随磁通扫过 p 模式， 提供"可变"且与 Q2 反号的耦合。二者相加得有效耦合 geff，调磁通即可让 geff 过零。

有效耦合与被标定对象

geff = g₁p g₂p/2 (1/Δ₁p + 1/Δ₂p) − g₁m g₂m/2 (1/Δ₁m + 1/Δ₂m)

ζ = E|11⟩ − E|10⟩ − E|01⟩ + E|00⟩ 即为 CZ 门要利用的 ZZ 相互作用 （高保真 CZ = 精确标定的 CPHASE）。

① idle 磁通 ② Z 脉冲失真 ③ CZ 相位 θ=π ④ 两个 VZ 相位

两比特失谐 464 MHz > 非谐性（−212 / −199 MHz），工作于 straddling regime 之外， 放宽数据比特失谐限制，但仍需检查高能级与耦合器的避免交叉；qb 与耦合器强排斥还带来一个便利： 数据比特自身频率对磁通灵敏，可用来当传感器标定 Z 脉冲失真——不需要耦合器读出谐振器。

02

能谱与 ZZ 相互作用：标定的物理基础

所有校准量都来自这条"磁通–能量"曲线：idle 点是 ZZ 的零点，磁性工作点是 ZZ 的极深点。 由于需要四 transmon 联合对角化，论文用 Hamiltonian 数值仿真与实测对照，再人工搜索电路参数。

为什么"大 ZZ"能实现快门？ CZ 门在绝热过程中扫过能谱：从 idle 点出发， 增大磁通让 |11⟩ 与耦合器态强烈排斥、累积 CZ 相位，再扫回。ZZ 越大，达到 π 相位的门长越短； 但伴随而来的是泄漏误差（非绝热跃迁）——这正是后面 RL 要优化脉冲形状的原因。
03

器件参数设计与搜索（附录 C）

CZ 校准前的前置工作：四 transmon 联合对角化给出 ζmin（残余 ZZ）与 ζmax（CZ 速度）， 二者都要满足 → 参数必须在"权衡面"上搜索。论文给出一套 5 步人工搜索流程，比四维盲扫高效得多。

5 步搜索流程（3–5 可反复迭代）

  1. 定比特频率与非谐性：4–5.5 GHz，非谐性 ≈ −200 MHz；失谐取 500 MHz（脱离 straddling）。
  2. 处理杂散电容：C14、C23、C12 < 1 fF 可忽略；C34 视为定值（Sonnet/COMSOL 给出）。
  3. 定耦合电容 Cg = C13 = C24：分电容的 5–10%（≈100–200 MHz 耦合），本文 5.7 fF。
  4. 固定 α 扫 {Cc, EJc}：α = EJ5/EJ3 应 < 0.25（本文 0.216）。
  5. 固定 Cc 扫 {EJc, α}：α↑ → 两耦合器耦合更强 → 间接增大比特间 ZZ。
核心权衡：Cc↑ 或 EJc↓ → 耦合器模式频率↓ → ζmin 与 ζmax 同时增大。 要"快门 + 低残余"必须精细平衡；ζmax 大虽让门更快，但留给其他参数的容差变小。
α < 0.25（经验上限） Cg = 5–10% 分电容 C34 ≈ 1.7 fF（定值） 杂散 < 1 fF 可忽略 工艺偏差：实测 ≠ 设计，需再调 仿真基准 = Eq.(1) 数值对角化

校准流程总览（8 步）

蓝色 = 电子学/基础标定；紫色 = 单比特；琥珀色 = Z 脉冲与 CZ 相位；绿色 = 相位补偿与验证。

STEP 0硬件
链路与电子学准备

SHFQC 出 XY+复用读出；HDAWG8 出 Z 并带实时预补偿；GS200 供超导线圈 dc；FS725 铷钟同步；独立 dc 线圈链路加 <1.6 kHz / π 低通。

STEP 1JAZZ
idle bias point

扫 dc 磁通用 JAZZ 找 ZZ 零点 → 0.309，残余 2π×(−6.3) kHz；单比特门与读出在同一工作点校准。

STEP 2DRAG+RB
单比特门精标

DRAG；单独/同时 RB 验证残余 ZZ 不伤单门 → Q1/Q2 ≥ 99.98%。idle 确定后精标，CZ 前完成，否则污染 CZ/VZ 相位。

STEP 3预畸变
Z 脉冲失真标定

把 Q2 当传感器：Ramsey+相位层析，分短期(603 ns…)/长期(400 μs…)拟合 {ak,τk}，回代 AWG 做 predistortion。

STEP 4RL(PPO)
CZ 相位优化

JAZZ-N 扫 Slepian 幅度 → θCZ≈π；再用 JAZZ2-N 保真度作 reward，PPO 优化脉冲形状（20 点→2 GSa/s 样条）。

STEP 5RL(PPO)
VZ 相位优化

Ramsey 型序列逐比特测 Z 累积相位作初值 → 两比特 RB 保真度作 reward 微调。Z 脉冲固定不动。

STEP 6QPT
PTM 复核

36 初态 × 36 投影重建 16×16 Pauli 转移矩阵，确认"这就是 CZ"（受 SPAM 低估，仅定性）。

STEP 7 · 8SRB/IRB/LRB
精度与误差预算

LRB 分离泄漏/去极化：rCZ=0.090%、L=0.027% → 99.90%；门长扫描定 48 ns。

三条硬性依赖顺序： ① 单比特门（STEP 2）必须先于 CZ/VZ 优化——单门相位误差会被误当作 VZ 相位； ② Z 脉冲失真（STEP 3）必须先于 RL——否则 agent 把学习容量浪费在补偿未知线路瞬态； ③ Z 形状与 VZ 相位必须分开优化：DTC 中数据比特被耦合器能级排斥，Z 脉冲期间频率动态变化， 使 VZ 相位对脉冲形状"高度敏感"，论文选择分开优化；实际改动 Z 波形后应重校 VZ。
05

STEP 1 · idle bias point 定标（JAZZ）

目标：用超导线圈把磁通精确钉在 ZZ 零点，作为所有单比特与 CZ 优化的起点。

核心公式

P|0⟩ = (1 − cos φ)/2,   φ = ζ·t/2 + φ₀
人为引入基线频率 ωb：   ζ = 2(ωm − ωb)

idle 点 |ζ| 仅 kHz 量级，受相干时间限制无法测到足够多个振荡周期 → 令末尾 π/2 相位随时间线性变化，人为把振荡频率抬到 ωb，再减掉基线即得 ζ。 取 ωb > |ζ/2| 保证 ωm 为正、避免符号混淆。

结果

φex/2π = 0.309 ζmin = 2π×(−6.3) kHz 解析估计 0.319

测大 ZZ（φ/2π≈0.47）时振荡太快，不需要基线技巧：最终门固定为 Yπ/2，ζ = 2ωm → ζmax = 2π×(−82.5) MHz。

STEP 2 · 单比特门精标（DRAG + RB）

STEP 3 · Z 脉冲失真标定与预畸变

快速磁通线带宽受限且有色散，方波 Z 脉冲结束后仍有"尾巴"，破坏理想绝热过程。 关键巧思：不给耦合器加读出谐振器，而是把 Q2 当传感器。

为什么 Q2 能当传感器？ 在 0.375 < φex/2π < 0.45 区间，Q2 频率被耦合器能级显著排斥， 从而对磁通灵敏（代价：该点 T₂ᴿ≈3 μs）。STC 方案通常需要一个可调比特做同样的事，DTC 只需一个调磁通元素。

STEP 4 · CZ 相位（θCZ = π）优化

"先物理、后 RL"两段式：先用 JAZZ-N 把脉冲幅度标到 θ≈π，再用强化学习把脉冲形状优化到位。

两条 reward 曲线

JAZZ-N：  P|1⟩ = (1 − cos[(2k+1)θCZ])/2
JAZZ₂-N：  P|00⟩ = (1 − cos[(2k+1)θCZ])/2 ⟶1

实测 N = 9, 41, 101（k = 2, 10, 25）逐级细化幅度。初始形态用 Slepian： 由 θ(t)=arctan(Hx/Hz)、dθ/dt = S(t) 得 θ(t)=∫S dt，再以 Hz/Hx≈C·z²(t) 映射到 AWG 电压。 48 ns 总长、首尾各 2 ns 零 padding。Gaussian/cosine 亦可，论文中主要影响优化效率；有限训练预算下不保证相同性能。

STEP 5 · VZ（virtual-Z）相位优化

虽然每个数据比特只有一个约瑟夫森结（形似定频），CZ 期间仍被耦合器能级排斥而频率动态变化， 各自累积附加 Z 旋转 θ₁、θ₂，必须用零成本的 virtual-Z 补偿。

物理初值（Ramsey 型 + 线性拟合）

Q1：θ₁/2 = 139.33° / 周期 Q2：θ₂/2 = −102.05° / 周期

比特频率标不准会引入附加相位污染 VZ 标定 → 用 echo 型序列（π/2−Z−π−I−Tomo）或先精标比特频率。

RL 微调

reward = 两比特 Clifford RB 的序列保真度；Z 脉冲保持固定，只优化 (VZQ1, VZQ2)； 每 epoch 生成 20 组，配 5 条随机 Clifford（m = 20）测均值。

读出误差限制本实验的优化灵敏度。论文明确指出：用 RB 进一步优化 VZ 是把相位误差压到 <1.5°（贡献 <0.01% 相干误差）的关键一步。

STEP 6 · QPT / Pauli 转移矩阵复核

36 个初态 × 36 个投影测量 + 最大似然重建，直观确认"这个门就是 CZ"；保真度仅作参考（受 SPAM 低估至 95.9%）。

制备

{X±,Y±,Z±}^⊗2 = 36 个初态，由 {Yπ/2, −Yπ/2, −Xπ/2, Xπ/2, I, Xπ}^⊗2 制备。

测量与重建

36×36 = 1296 个投影结果，态层析 + Pauli 基底矢量化 + 最大似然重建 Rij = ⟨i|R|j⟩。

保真度

F = [Tr(RidealTR) + d]/[d(d+1)], d=4

实验结果 0.959（SPAM 主导的低估）。

STEP 7 · 精度评估：LRB / SRB / IRB

有泄漏时标准 RB 必须改造：同时拟合"总残留概率"与"理想态存活率"，把泄漏、去极化、SPAM 分离开。

公式链

L₁ = (1−λL)(1−A),   r = (1−λr)(1−1/d),  d=4
L₁CZ = 1 − (1−L₁IRB)/(1−L₁SRB)
rCZ ≈ ((d−1)/d)·(1 − λrIRB/λrSRB)
F̄ = 1 − L₁CZ/d − rCZ
量本文结果
rCZ（Clifford IRB）0.090 ± 0.009 %
L₁CZ（泄漏）0.027 ± 0.006 %
平均保真度 F̄99.90 ± 0.01 %

LRB 比忽略泄漏的常规 RB 给出的保真度低 L₁/d——泄漏虽小但不能不计。数据点为 10 条随机序列的平均±标准差。

STEP 8 · 误差预算与门长选择

总 infidelity 0.10% = 泄漏 0.027% + 去极化型 0.090%；相干相位误差 <1.5° ⇒ 贡献 <0.01% 可忽略。

非相干误差模型

1−F ≈ (2/5)(t/T₁1+t/T₁2+t/Tφ1+t/Tφ2) + (3/10)(t/TCZ) ≡ (2/5) t/Teff

Teffexp = 23.9 ± 1.5 μs，明显低于由 idle 点 T₁/Tφ 估算的 Teffest = 67.6 ± 11.4 μs ⇒ 存在"CZ 期间的额外退相干"（多能级混合 + Z 脉冲激活的噪声通道）。

1/f 磁通噪声可忽略：√AΦ≈4.84 μΦ₀，Monte Carlo 给出 40–320 ns 门长内误差 <10⁻⁶。

12 小时稳定性

6 次 rCZ 全部 <0.1%（平均 0.09±0.01%），L₁ 平均 0.030±0.003%。 期间 CZ 参数只优化一次，单比特门每次 RB 前重标（温度漂移是主要不稳定源）。

复现清单与易踩坑

按依赖排序的可执行顺序，以及论文明确点出的坑。

✅ 可照搬的校准顺序

  1. 基础：谐振器频率/功率、k-means 单发分类（含 |2⟩）；SHFQC/HDAWG/铷钟同步。
  2. XY：DRAG（幅度/β/频率）→ 单独 + 同时 RB。
  3. 磁通：dc 粗扫 + JAZZ 找 idle point → dc 源锁定 + 强低通滤波。
  4. 失真：强耦合灵敏点（0.375–0.45）小幅度测短期、长脉冲测长期 → {a,τ} → 预畸变。
  5. CZ 相位：JAZZ-N 扫幅度（N=9→41→101）→ Slepian 初值 → JAZZ₂-N + PPO 优化形状。
  6. VZ：Ramsey 型逐比特标定（先用 echo 或精标频率）→ RB + PPO 微调。
  7. 验证：QPT 看 PTM → LRB 出精度 → 门长扫描选 tgate。

⚠ 论文明确点出的坑

  • 不先标 Z 失真就上 RL：agent 会用容量补偿未知瞬态，效率低甚至不收敛。
  • 在 DTC 中联合优化 Z 形状与 VZ 相位"极难"（能级排斥致 VZ 对形状极敏感）——必须分两步。
  • 门长短于约 40–48 ns：泄漏误差可能因 RL/带宽限制而反弹（本文 40 ns 约 0.1%）。
  • 门长长于 100 ns：泄漏占比变小后 RL 优化敏感度下降，泄漏又缓慢上升。
  • 单比特门要反复重标，否则温度漂移污染 CZ/VZ 相位评估。
  • 读出噪声限制 VZ/RL 优化灵敏度，不能据此给门保真度设普适上限。
  • QPT 保真度受 SPAM 严重低估（95.9%），最终以 RB 为准；RB 需改造为 LRB 才能计入泄漏。

🔧 硬件取舍

可省：耦合器读出谐振器（失真标定用比特传感器即可，只需保留它做泄漏表征）。 建议保留：AWG 侧实时预补偿、dc 低通（<1.6 kHz + π）、μ 金属双层屏蔽。
